# 08_gauntlet — compare blind against the bar

One job: a harsh critic puts our output next to the real bar and picks one.

## Inputs
- Working: `BAR.md`, `GATES.md`, artifacts (audio files, screenshots, recordings)
- Reference: `../../_shared/standards/bar-and-gauntlet.md`

## Process
1. Fetch the bar for real (the demo video, the live page, the audio sample). Never compare against a description.
2. Strip labels. Ask: which is better for THIS job? A/B/TIE, with cited evidence.
3. Score the weighted card (universal + web/voice sub-scores). Hard floors apply.
4. If ours loses: name the single biggest gap → route to the right stage → bounded repair slice → re-verify → compare again.

## Outputs
- `GAUNTLET.md` (verdict, scores, gap list), `STATE.md` → `next_stage: 09_release` or `06_build`

## Human check
None until ours wins; then the owner sees the comparison.
