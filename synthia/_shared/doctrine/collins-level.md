# Collins-level protocol — condensed for SYNTHIA (owner PDF is canonical)

Standard: clear, ownable, culturally relevant, emotionally compelling, commercially useful, accessible, responsive, technically verified. Easy to use AND hard to imitate honestly.
Principles: strategy before styling · distinction before decoration · self-evident before experimental · content before containers · systems before isolated screens · proof before claims.
Project lock fields: MODE, OUTCOME, TARGET, PRIMARY ACTION, CONSTRAINTS, PROTECTED ASSETS, PROOF, COMMERCIAL VALUE, CLASSIFICATION (SELL/USE/MERGE/PARK/ARCHIVE).
Gates: 1 customer sentence (When [situation], [customer] needs to [job], because [stakes], but [barrier], so they can [outcome]) · 2 positioning without empty adjectives · 3 every visual decision connects to positioning/need/content/behavior/function · 4 owner selects one of three divergent territories · 5 reject template-born components.
Page definition per page: NAME, PRIMARY USER, SITUATION, PURPOSE, PRIMARY QUESTION, PRIMARY ACTION, REQUIRED PROOF, ENTRY, EXIT, SUCCESS METRIC.
Build specification: layout, components, content, responsive, tokens, animation, interactions, accessibility, performance, analytics, data, errors, security, ownership, deployment, rollback. No "make it premium".
Acceptance example: Given 390 px, when the page loads, no horizontal overflow, headline fully visible, CTA reachable, nav opens by keyboard and touch.
First slice: primary landing → offer → proof → conversion → confirmation → analytics event; independently verified before scaling.
Six independent reviewers: customer-value, Krug usability, creative director, accessibility, technical, sovereignty.
Scores (web): strategy 12, customer 8, content 10, IA 8, usability 14, visual 12, originality 12, responsive 7, accessibility 7, performance 5, conversion 3, ownership 2. Floors: overall ≥ 8.5; usability/visual/originality/accessibility ≥ 8.5; primary conversion ≥ 9.0; critical failures/broken controls/mobile overflow/unverified claims = 0; rollback documented; owner approval recorded.
Cliché blacklist: generic centered hero, purple-blue gradients, glassmorphism, floating dashboard mockup, three-card feature row, bento, pill-everything, random luxury serif, stock lifestyle photos, decorative 3D spheres, marquee, arbitrary parallax, template testimonials, fake metrics, AI-brain imagery.
Motion: serves hierarchy, orientation, feedback, narrative pacing, or brand — never decoration on every section; reduced-motion alternative required.
